## Intro

- タイトル: 自分について
- レイアウト（手書きイメージ準拠）:
  - **左**: 縦長の自己紹介テキスト枠（トリコロール額縁）
  - **右**: それより低い小さめ横長画像（`aspect-[16/10]`）
  - **lg+**: 横並び、幅比 roughly テキスト 52% / 画像 48%（`max-w-4xl` 内で広め）
  - **SP**: 縦積み（上=テキスト全幅 / 下=画像）
- 画像: `/products/top_about.jpg`（`aspect-[4/3]`・`object-cover`・幅・高さともテキストに近いサイズ）
- セクション上部余白: `pt-20`〜`pt-24`（ヘッダー下を広めに）

- 左上に帯
- 自己紹介ブロック背景: ネイビー寄り（明度高め）+ 縦方向 padding 多め、文字はクリーム

## Skill

- 見出し: `▫️できること ーSKILLー`（左寄せ、横並び）
- `▫️` = トリコロールの細い縦長バー
- 背景: `#f3efe6`
- レイアウト: **2 カラム**（SP は 1 カラム）。各行は左に **スキル別アイコン**＋名前＋短い補足、右に ★
- アイコン: 線画 SVG（`text-brown`）。各スキル個別（`SkillIcon` in `components/site.tsx`）
- レベル文言は各行に重複表示せず、下部の凡例のみ
- レベルは **常に 4 枠**（塗り ★ / 空き ☆）。見出しフォントや字間は当てない（字形が崩れるため）
  - ★☆☆☆ 学習経験あり
  - ★★☆☆ 調べながら対応可能
  - ★★★☆ 実務経験あり
  - ★★★★ 実務で自力対応可能
- 一覧（`skills` in `components/site.tsx`）:
  - HTML / CSS（実務で自力対応可能）— コーディング・レスポンシブ
  - JavaScript / jQuery（実務で自力対応可能）— フロントの動き・UI
  - WordPress（実務で自力対応可能）— 構築・カスタマイズ・運用
  - TYPO3（実務経験あり）— 構築・運用
  - Movable Type（実務経験あり）— 構築・運用
  - Java / Spring（実務経験あり）— 業務Web・サーバーサイド
  - FlutterFlow（実務経験あり）— アプリ制作
  - React / TypeScript（調べながら対応可能）— 画面改修・フロント実装
  - Illustrator / Photoshop（調べながら対応可能）— 画像加工・デザイン補助
  - Premiere Pro（調べながら対応可能）— 動画編集
  - After Effects（学習経験あり）— モーショングラフィックス基礎
  - SQL（学習経験あり）— 学習中・データ確認
