# 指示出しテンプレ

← [README](./README.md)

## 使い方

1. `docs/README.md` と対象ページの MD を確認させる
2. 変更内容を短く書く
3. 下の実装プロンプトを添える

スレッドで出した指示は、実装とあわせて **該当する `docs/*.md` にも反映する**（`.cursor/rules/docs-sync.mdc`）。

例:

```
docs/about.md を確認してください。
Career の文言を ○○ に更新してください。
その方針で実装してください。実装後に変更内容を簡潔に説明してください。
```

## 実装プロンプト（定型）

```
その方針で実装してください。
実装後に、変更した内容を簡潔に説明してください。
```

## 表示・完了の書き方（任意）

### 表示する内容

- （何を見せるか）

### 条件

- レスポンシブ対応
- 既存デザイン（フォント・色・世界観）を崩さない
- 外部ライブラリは必要時のみ

### 完了条件

- 指示内容がブラウザに表示される
- 画面表示時にエラーがない
